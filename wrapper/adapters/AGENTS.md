# Context Circuit entry adapter

This is the small safety spine shipped into a workspace. Read it first with
`WORKFLOW.md`, `wrapper/manifest.yaml`, the workspace identity fields, and the
three context summaries. Select one bounded probe before reading deeper files.

Host and repository instructions remain higher authority. Runtime evidence,
handoffs, and receipts never override accepted context, plans, Git state, or a
human gate. `sources/` is passive and request-scoped; never scan it broadly.

The complete rule ownership map is in `wrapper/contracts/invariants.yaml`.
