# Intents

An intent describes the goal, non-goals, constraints, success criteria, and rough
repository scope. The user approves the outcome before code-grounded planning.
Use the executable to create iNNN-slug.md records and reserve global IDs.
Link plans by their IDs. Approval records the instant in `approved_at`; an
unapproved intent has no such field. Approval is an actual conversational human
decision; an editable record holds it, not an authentication mechanism.
