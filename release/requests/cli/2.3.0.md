# Context Circuit CLI 2.3.0

`init` no longer requires a member. Without `--member` it creates a solo
workspace with an empty roster: no member is selected on any machine, and
records carry no `created_by`. Adding the first member makes it a team
workspace, and records written before that stay valid.

In a workspace that lists members, `status` now reports `identity_required`
when this machine has selected no member, or names one the roster does not
carry, and `record create` says how to settle it. Selection is taken as given;
nothing verifies who a person is.

`record delete --member ID` removes every intent and plan one member created,
active and archived, and releases their IDs so allocation hands those numbers
out again. `record delete --all` does the same for every record in a solo
workspace and resets the ledger. Without `--confirm` it previews and deletes
nothing. It refuses while another member's record would be left pointing at a
deleted one, or while a worktree on this machine was prepared for a deleted
plan.
