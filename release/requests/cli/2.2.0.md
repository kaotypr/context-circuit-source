# Context Circuit CLI 2.2.0

New plans are created as `plans/pNNNN-slug/plan.md`, with optional supporting
files assigned through `required_files`. The CLI accepts plans without an intent,
selects exact runs with repeatable `record order --plan ID`, and briefs workers
with only the details assigned to their repository. Diagnostics report missing,
unsafe, unlinked, and unassigned supporting files. Existing single-file plans
remain readable and editable without migration.
