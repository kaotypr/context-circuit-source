# Context Circuit 1.0.1

This release requests the following changes:

- **Number intent open questions (i025-number-intent-open-questions).** New intents use stable numbered questions so users can answer by number. Empty question sections retain their existing empty-state text.
- **Reliable role-tiering config access (i028-role-tiering-config-access).** The `role-tiering-read` engine verb reads the workspace-root local configuration directly and uses the committed fallback when no local override exists. Host and role instructions point to the shared configuration documentation.
- **Runnable worktrees (i027-runnable-worktrees).** New execution and Explore worktrees receive copies of the bound checkout's gitignored paths, then provision dependencies against their own lockfiles. Setup reports ready only after preparation succeeds; failures prevent worker attachment.

The maintainer source cleanup removes active and archived intents and plans. Local runtime records and worktrees were also cleaned up; runtime implementation code remains in place.
