Ships the v1.0.0 runtime layer on top of `0.0.1-alpha.4` (v0.7.0). This is the
first release of the two-gate lifecycle and its bounded assurance model:

- **Intent front door and scope envelope.** A first-class intent contract
  captures the goal, non-goals, constraints, acceptance criteria, repository
  and path scope, and assurance tier. A spec adversary attacks the proposed
  criteria before the intent is accepted, and the runtime mechanically enforces
  the repository/path envelope.

- **Plan contract v3.** Standard and Critical plans require an accepted intent;
  plan-level approval is removed. Legacy plan schemas are no longer executable
  by the v1 runtime and require human-assisted migration when still in flight.

- **Candidate identity and staleness.** Execution evidence is bound to a
  candidate so changes after verification invalidate stale acceptance. A change
  set can be prepared and verified once at its integration tip for one delivery.

- **Tiered assurance.** Explore work uses the human-supervised `cc-pair` path;
  Standard and Critical work require an independent verifier, with Critical
  completion remaining an explicit human decision. Tier classification fails
  upward when risk signals are present or uncertain.

- **Closed knowledge loop and completion.** Accepted work can emit inferred
  completion at the appropriate tier, while reconciliation debt and pending
  context proposals remain visible until human disposition. Delivery remains a
  separate explicit action.

- **Repository terminology migration.** The canonical binding and execution
  record field is now `base_branch`; schema-1 `anchor_branch` bindings remain
  readable and can be migrated explicitly to schema 2 with
  `repository-binding-migrate`. New writes use the base-branch spelling.

Internal `runtime_version` is `1.0.0`. The release preserves the existing
workspace, repository, plan, source, context, and runtime state during upgrade;
the template release version is stamped as `0.0.1-beta.1` in the destination
template repository.
