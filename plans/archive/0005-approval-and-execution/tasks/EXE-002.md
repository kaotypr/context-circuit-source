## Intended behavior

Execution begins by capturing each affected repository's base tip (rejecting a
dirty base checkout), snapshotting the plan into an immutable
plan-snapshot, and acquiring the single writer lock. One branch
(`cc/<plan-id>/<repo-id>`) and one worktree are created per affected repository
from the captured base tip; the base checkout is never written. The single
worker implements tasks in dependency order, modifies only listed paths in its
assigned worktrees, and commits each changed repository before verification.

## Concrete change and affected surfaces

Add execution-begin, worktree preparation, commit capture, and branch-revision
validation to `wrapper/runtime/engine.sh`. Author `agents/writer.md` defining
the sole-writer role and its prohibitions (no base-checkout writes, no status
changes, no scope expansion, no self-verification, no merge/push/publish/deploy/
delete). Writer prompts read the immutable plan snapshot, not the live plan
directory.

## Inputs and outputs

Inputs: an approved plan and its captured base tips. Outputs: per-repository
branches and worktrees, an immutable plan snapshot, per-repository commits, and
recorded commit revisions validated to belong to assigned branches.
