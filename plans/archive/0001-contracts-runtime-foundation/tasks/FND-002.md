## Intended behavior

The runtime is a small POSIX-sh deterministic library that owns state mutation
and nothing intelligent. It provides safe identifier and path validation, atomic
record writes, content digests, and a simple atomic exclusive-create one-writer
ownership lock, so a partial record can never grant ownership, resume a writer,
prove verification, or permit completion.

## Concrete change and affected surfaces

Implement the primitives in `wrapper/runtime/engine.sh`: safe path/id checks,
atomic writes (write-temp-then-rename), content digests, and the exclusive-create
one-writer lock (INV-OWN-01). Enforce the runtime exclusion list: no
provider-specific launch code, no model prompts, no Product Knowledge
interpretation, no plan-writing behavior, no broad conversation router as policy
owner, no confirmation-card rendering, and no pull-request/merge/push/publication/
deployment or automatic completion. The runtime is the host-neutral implementation
library only; the human interface stays conversational.

## Inputs and outputs

Inputs: a workspace root and operation arguments passed by the host adapter.
Outputs: atomic runtime records and structured results with reason codes; the
one-writer lock file. No provider payloads or prompts are produced.
