## Intended behavior

The grounding contract is fixed in the invariants and the role files. Before
implementing, the writer must read and honor the repository's own agent guidance
discovered live from the worktree (INV-GROUND-01). Precedence is explicit: the
brief's scope and safety rules are authoritative on what and where; the repository
guidance is authoritative on how to write code within that scope and never
overrides a Context Circuit safety or scope rule (INV-GROUND-02). The coordinator
delivers the brief and authors only the one-line task focus, never the fact
sections (INV-GROUND-03).

## Concrete change and affected surfaces

Add INV-GROUND-01, INV-GROUND-02, and INV-GROUND-03 to
`wrapper/contracts/invariants.yaml` and extend the worker-behavior rules with the
read-and-honor obligation. Update `agents/writer.md` with the obligation to read
discovered guidance, apply relevant skills by description, and stop-and-report on a
scope/safety conflict. Update `agents/coordinator.md` so it delivers the assembled
brief and adds only the task focus, never authoring the repository fact sections.

## Inputs and outputs

Inputs: the assembled writer brief and grounding directive, the discovered
repository guidance in the worktree. Outputs: the three INV-GROUND invariants and
worker-behavior extension in `invariants.yaml`, and the updated coordinator and
writer role contracts enforcing deliver-not-author and read-and-honor with correct
precedence.
