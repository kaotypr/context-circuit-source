## Intended behavior

Make the harness efficiency ledger (dimension D) real while keeping it soft and
warning-only. The `claude-code` driver derives a per-action `$CC_TELEMETRY` ledger
from each coordinator turn's own `result` event — no model call and no change to
how the coordinator runs — and the grader compares observed usage to each case's
`budgets`, reporting WITHIN/OVER per field. With no ledger, dimension D degrades to
"unavailable" as before, and the verdict is never changed.

## Concrete change and affected surfaces

In `template-harness/human/run-scenario.sh`, emit the extended, additive TSV ledger
per action tag: `conv_turns`, `agent_turns` (summed `num_turns`), `output_tokens`
(summed `usage.output_tokens`), `context_peak` (max `cache_read_input_tokens`), and
`cost_usd` (summed `total_cost_usd`), reusing the existing per-turn action tag. In
`template-harness/human/grade.sh`, define the budget units (`max_tokens` = output
tokens, `max_turns` = conversational turns, optional `max_agent_turns`,
`max_cost_usd`) and compare each ledger row to its action's `budgets` with a
deterministic awk/shell check, printing observed vs budgeted and the reported
`context_peak` diagnostic. In `template-harness/scenarios`, recalibrate the affected
case budgets (cases 10 and 11) from measured green runs with 1.5–2x headroom.

## Inputs and outputs

Inputs: each coordinator turn's `result` numbers (`num_turns`,
`usage.output_tokens`, `usage.cache_read_input_tokens`, `total_cost_usd`) and each
case's `budgets`. Outputs: the `$CC_TELEMETRY` TSV under the disposable per-run
directory, per-action WITHIN/OVER report lines, and recalibrated case budgets. The
human-simulator's verdict call stays in its own file and never enters the ledger.

## Risks and open questions

- Attribution is heuristic (a turn's whole usage is charged to its action tag), so
  the ledger must stay reported, never gated.
- `context_peak` is tracked and reported but is a diagnostic, never a budget; A/B/C
  forbidden checks remain the only hard gates. Source-only tooling: nothing ships.
