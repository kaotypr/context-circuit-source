## Intended behavior

The cc-complete skill maps human "mark complete" language to the gated
human-only completion followed by knowledge reconciliation. It refuses to
complete a plan when the latest execution is not verified, and it never accepts
resulting context proposals on its own.

## Concrete change and affected surfaces

Author `.agents/skills/cc-complete/SKILL.md` so it invokes the completion
eligibility and record primitives (CMP-001) and starts reconciliation (CMP-002)
through `wrapper/runtime/engine.sh`. The skill drives the conversational
interface; it does not add parallel policy already owned by the runtime and
invariants. It reports the completion outcome and any pending context proposals
in plain language.

## Inputs and outputs

Inputs: a human request to complete a named plan and the current execution
verification state. Outputs: a refusal when the latest execution is not verified,
or a completed plan plus a reported context-impact result when it is.
