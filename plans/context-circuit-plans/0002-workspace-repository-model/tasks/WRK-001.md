## Intended behavior

The workspace carries a portable identity that holds only a logical key,
optional credential-free canonical URL, and optional default_branch, with no
machine path or secret. The host-local binding schema holds the concrete
checkout path and a required per-repo anchor_branch that owns the execution base;
default_branch is clone/setup guidance only and never the execution base.

## Concrete change and affected surfaces

Author `wrapper/contracts/schemas/workspace.yaml` as the portable identity shape:
workspace name, purpose, and logical repository identities (id, purpose, optional
canonical_url, optional default_branch) — no paths, no credentials (INV-REPO-02,
INV-SEC-01). Author `wrapper/contracts/schemas/repositories-local.yaml` as the
gitignored `repositories.local.yaml` binding shape: per-repo path plus required
anchor_branch (INV-REPO owners). The reserved logical id `workspace` binds the
workspace root at `.` with its own anchor branch.

## Inputs and outputs

Inputs: the v0.5 workspace-and-repositories model. Outputs: two contract schema
files — the portable identity shape and the host-local binding shape.

## Stop conditions
