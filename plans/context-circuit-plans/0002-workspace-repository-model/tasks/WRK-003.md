## Intended behavior

The coordinator has a read-as-procedure packet for orienting in a workspace and
registering repositories. Orientation is strictly read-only; registration binds
a logical identity explicitly and maps "connect/clone/init repo" language onto
registration plus local binding, never an inferred or scanned path.

## Concrete change and affected surfaces

Author `.agents/skills/cc-workspace/SKILL.md` (INV-SKILL-01 path convention) as
the cc-workspace packet covering: orient (report identity, registered repository
keys and binding availability, Product Knowledge areas, and active plans without
creating an execution record), register (record portable logical identity and add
a host-local binding with base_branch), and bind. Map the user's plain
"connect", "clone", and "init" requests to registration and binding, reporting
source URL, destination, branch, and external Git effect before any separate
bootstrap action.

## Inputs and outputs

Inputs: a natural-language orientation or repository request from the user.
Outputs: a plain-language orientation summary, or an explicit registration and
binding, using the runtime primitives from WRK-002 for the side-effecting steps.
