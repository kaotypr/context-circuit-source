## Intended behavior

The runtime resolves and preflights repository bindings fail-closed: a missing,
ambiguous, non-Git, or mismatched binding is rejected without scanning the
machine. Clone or `git init` into `repositories/` happens only on explicit
request. Execution prepares a deterministic worktree and branch from the captured
anchor tip; the anchor checkout itself is never written.

## Concrete change and affected surfaces

Extend `wrapper/runtime/engine.sh` with: binding resolution and preflight that
reject missing paths, non-Git paths, traversal outside permitted roots, unsafe
symlinks, remote identity conflicts, duplicate/ambiguous bindings, and dirty
anchor checkouts (INV-REPO-04); no filesystem scan for a matching name. Add
explicit-only clone and `git init` bootstrap into `repositories/<id>/`. Add
deterministic worktree preparation: validate the anchor branch, capture its tip
as the immutable base commit, and create `cc/<plan-id>/<repository-id>` branch
and worktree from that snapshot without moving or rebasing the anchor.

## Inputs and outputs

Inputs: resolved workspace identity and `repositories.local.yaml` bindings, a
plan id, and a repository id. Outputs: preflight results with reason codes, a
prepared worktree root and execution branch, and the recorded anchor branch,
base commit, and cleanliness in the execution record.
