## Intended behavior

The cc-deliver skill maps "open a pull request", "merge", and "push" language to
the explicit delivery boundary from DEL-001. Each delivery verb is a distinct
explicit action requested by the human, never a side effect of execution,
verification, or completion.

## Concrete change and affected surfaces

Author `.agents/skills/cc-deliver/SKILL.md` so it drives the delivery boundary
defined in `wrapper/adapters/WORKFLOW.md` and computed by
`wrapper/runtime/engine.sh`. The skill confirms source branch and target anchor
branch before acting, reports blocked delivery when a source, provider, or target
is unavailable, and never infers a remote or substitutes `default_branch`. It
owns only the conversational mapping, not parallel delivery policy.

## Inputs and outputs

Inputs: an explicit human delivery request naming the verb and plan. Outputs: a
delivery action performed only on explicit confirmation, or a blocked-delivery
report identifying the missing source, provider, or target.
