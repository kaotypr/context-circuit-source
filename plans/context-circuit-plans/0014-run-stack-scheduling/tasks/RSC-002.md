## Intended behavior

The product gains a conversational action to run a named set of already-approved
plans in one request — "execute plans X…Z" / "run the ready stack" — beside the
singular "execute plan X". The action adds no new authority: it only decides order
and overlap among plans a human has already approved, and it executes only
already-approved plans, refusing an unapproved plan in the set without blocking
the rest.

## Concrete change and affected surfaces

Add the "Execute plans X…Z / run the ready stack" conversational action to
`wrapper/adapters/WORKFLOW.md` beside the existing singular execute action.
Author `.agents/skills/cc-run-stack/SKILL.md` as the read-as-procedure packet that
drives the run-stack loop over the approved set, deferring readiness/lease/base
detection to the runtime and launch concurrency to the coordinator.

## Inputs and outputs

Inputs: a conversational request naming a set of approved plans, plan approval
state. Outputs: the run-stack action in WORKFLOW.md, the cc-run-stack skill
packet, and a run that executes only approved plans (unapproved plans refused,
others unaffected).
