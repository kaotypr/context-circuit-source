# Define runtime records, leases, handoffs, and recovery invariants

## Description

Specify and implement the filesystem contract for session identity, parent/root relationships, plan ownership, leases, durable handoffs, recovery, stale state, and safe concurrent updates.

## Implementation scope

- docs/agent-workspace-workflow.md
- WORKFLOW.md
- docs/development.md
- .runtime/*
- workspace.yaml

## Test scope and expectations

- docs/agent-workspace-workflow.md
- .runtime/*
- test

- Required fields and legal lifecycle transitions are defined for root and child sessions, plan leases, worktree ownership, and handoffs.
- The contract has no global current-session or current-plan pointer and defines conservative behavior for stale, partial, or contradictory records.
- Lease acquisition and release are safe under concurrent attempts, with an explicit owner and contention result.

## Verification commands

- git diff --check
- node .agents/bin/cc.mjs validate

## Acceptance criteria

- A filesystem-only fixture can represent two independent plans, their sessions, leases, worktrees, and handoffs without path collisions.
- An interrupted or stale session cannot be silently treated as the active owner without explicit recovery evidence.
