# Implement child-session delegation and handoff protocol

## Description

Define the bounded child-session packet and structured return handoff, then apply it to repository workers and independent verifiers so subagents know exactly what they own and when to stop.

## Implementation scope

- agents/coordinator.md
- agents/repository-worker.md
- agents/reviewer.md
- docs/run-task.md
- docs/agent-workspace-workflow.md
- context/CONVENTIONS.md

## Test scope and expectations

- agents/coordinator.md
- agents/repository-worker.md
- agents/reviewer.md
- test
- .runtime/*

- A child packet includes session IDs, role, objective, scope, non-goals, plan/task, context references, worktree, permissions, acceptance criteria, stop conditions, and handoff schema.
- A worker cannot claim ownership outside its assigned worktree and a verifier cannot mutate worker, plan, or activity state.
- Handoffs distinguish completed, blocked, failed, and awaiting-human-gate outcomes and include reproducible evidence.

## Verification commands

- git diff --check
- node .agents/bin/cc.mjs validate

## Acceptance criteria

- A root session can delegate two different bounded tasks to child sessions and reconcile both handoffs without ambiguous ownership.
- A child session reaching a stop condition leaves a durable handoff that allows safe resume or human escalation.
