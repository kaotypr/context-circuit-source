# Document the migration gate and prepare deferred cleanup handoff

## Description

Document how reviewers decide that the replacement has passed, preserve the old command layer during that decision, and produce only a handoff/request for a separate cleanup plan after the gate is satisfied.

- docs/command-reference.md
- docs/development.md
- docs/planning.md
- docs/run-task.md
- docs/using-the-wrapper.md

## Test scope and expectations

- docs/command-reference.md
- docs/development.md
- context/DECISIONS.md
- .agents/bin/cc.mjs
- scripts

- Documentation labels the Node/JavaScript command layer as transitional and does not claim it has been removed.
- The replacement acceptance result, verifier evidence, and human decision are recorded before cleanup is proposed.
- No cleanup deletion, branch removal, merge, or publication occurs in this implementation plan.

## Verification commands

- git diff --check
- node .agents/bin/cc.mjs validate
- The existing repository test command

## Acceptance criteria

- This plan ends with a clearly reviewable migration gate and a separate cleanup-plan trigger, not with deletion of Node/JavaScript files.
- A reviewer can identify exactly which acceptance evidence must pass before requesting the cleanup plan.
