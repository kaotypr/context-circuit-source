# Remove the legacy command layer and finalize the pure workflow

## Description

Remove the old Node/JavaScript command layer, generated bundle, command-specific host adapters, and release workflow after the filesystem acceptance contract is documented in the same approved rebuild plan.

## Implementation scope

- docs/development.md
- docs/planning.md
- docs/run-task.md
- docs/using-the-wrapper.md
- context/DECISIONS.md
- test/acceptance.sh

## Test scope and expectations

- docs/development.md
- test/acceptance.sh
- core instruction and runtime documents

- Documentation identifies agent instructions and filesystem state as the only supported workflow.
- The command layer, generated bundle, command adapters, and release workflow are absent from the repository.
- The acceptance suite remains runnable without Node, JavaScript, npm, or a generated command bundle.

## Verification commands

- git diff --check
- `sh test/acceptance.sh`

## Acceptance criteria

- This plan ends with a reviewable pure-workflow implementation and explicit absence checks for the old command layer.
- A reviewer can reproduce the acceptance evidence from the filesystem without relying on the removed runtime.
