# Implement root session entry and resume behavior

## Description

Make a root agent session the practical entry door for fresh work, existing PRDs, active plans, interrupted sessions, and blocked states using the normative instructions and runtime records.

## Implementation scope

- AGENTS.md
- CLAUDE.md
- agents/coordinator.md
- docs/getting-started.md
- docs/using-the-wrapper.md
- docs/planning.md
- docs/agent-workspace-workflow.md
- .agents/skills/*

## Test scope and expectations

- test
- docs/getting-started.md
- docs/using-the-wrapper.md
- .runtime/*

- Fresh entry discovers the workspace and reports the next safe action rather than assuming a plan or session.
- Resume reconstructs state from explicit session, plan, task, lease, worktree, and handoff records.
- A root session can coordinate several plans and can pause for a human gate without corrupting runtime state.

## Verification commands

- git diff --check
- `sh test/acceptance.sh`

## Acceptance criteria

- The root-session entry procedure is understandable to an agent without a user-facing CLI command.
- Fresh, resume, blocked, and completion-gated outcomes are all explicit and evidence-based.
