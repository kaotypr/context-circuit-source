# Integrate lease and exclusive worktree ownership with plan execution

## Description

Adapt plan execution so a worker must hold the plan lease and an exclusive plan-scoped worktree, while keeping the existing Node/JavaScript command layer as a compatibility adapter until replacement acceptance passes.

## Implementation scope

- scripts/lib/run-task.ts
- .agents/bin/cc.mjs
- docs/run-task.md
- docs/plan-publication.md
- workspace.yaml
- agents/repository-worker.md

## Test scope and expectations

- scripts/lib/run-task.ts
- .agents/bin/cc.mjs
- test
- .runtime/*

- Different plans can execute concurrently with distinct runtime identities, leases, branches, and worktrees.
- Same-plan lease contention is deterministic and non-destructive.
- The legacy command layer remains available for transitional validation and does not become the user-facing entry contract.
- Base checkout, other plan worktrees, wrapper config, and activity state are protected from worker writes.

## Verification commands

- git diff --check
- node .agents/bin/cc.mjs validate
- The existing repository test command

## Acceptance criteria

- A worker cannot start or continue plan execution without a valid lease and assigned worktree.
- Legacy Node/JavaScript validation/tests pass unchanged or with compatibility-only adjustments, and no legacy file is deleted by this task.
