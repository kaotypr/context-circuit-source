# Build the filesystem acceptance-test suite

## Description

Create an independent fixture-driven suite that exercises the complete Agent Workspace Workflow, including concurrency, ownership boundaries, interruption recovery, contradictory context, failed verification, and human completion gates.

## Implementation scope

- test
- test/helpers.ts
- test/simplified.test.ts
- docs/agent-workspace-workflow.md
- .agents/bin/cc.mjs

## Test scope and expectations

- test
- .runtime/*
- docs/agent-workspace-workflow.md

- The suite covers fresh root entry, PRD/idea orientation, child delegation, concurrent plans, same-plan lease contention, exclusive worktrees, interruption/resume, scope violation, contradictory context, verification failure, and completion gating.
- Core assertions inspect filesystem artifacts and invariants directly rather than treating the old CLI output as proof of replacement behavior.
- The verifier path is read-only and tests are repeatable from isolated temporary fixtures.
- The suite records enough evidence to decide whether the replacement acceptance gate has passed.

## Verification commands

- git diff --check
- node .agents/bin/cc.mjs validate
- The new Agent Workspace acceptance-test command or fixture runner
- The existing repository test command

## Acceptance criteria

- Every acceptance scenario in docs/agent-workspace-workflow.md has an executable or explicitly agent-replayable test case.
- A deliberately failing lease, scope, or verification fixture fails the suite for the correct reason.
- The passing suite provides the evidence required before any legacy cleanup plan can be opened.
