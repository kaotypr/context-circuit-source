# Getting help

## Questions

Ask how to use Context Circuit in
[GitHub Discussions, Q&A](https://github.com/kaotypr/context-circuit-source/discussions/categories/q-a).

## Bugs

Report a defect as a
[new issue](https://github.com/kaotypr/context-circuit-source/issues/new). Say
what you did, what happened, and what you expected.

## Security

Follow [SECURITY.md](SECURITY.md). Never report a vulnerability in a public
issue or discussion.
