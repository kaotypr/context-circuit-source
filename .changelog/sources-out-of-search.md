A shipped root `.ignore` with `/sources/` keeps `sources/` out of ripgrep-based
search, including Claude Code's Grep and Glob, and Cursor's search, so the rule
to leave sources unread unless named now holds on each host's smallest model. A
file named by the person or the task still opens, and `AGENTS.md` says to leave
the folder out of searches that ignore the file.
