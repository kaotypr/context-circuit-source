# Development

Install dependencies with `npm install`.

Run the repository checks with:

```sh
npm run typecheck
npm run validate
npm test
npm run build:template
```

The canonical implementation is under `scripts/lib/` and the CLI dispatch is `scripts/cc.ts`. Host skills under `.agents/`, `.codex/`, and `.claude/` are thin adapters. `.agents/bin/cc.mjs` is generated by `build-template` and must be rebuilt after source changes.

The template build bundles the command and produces a neutral `.dist/context-circuit-<version>.tar.gz`. It excludes maintainer scripts, tests, fixtures, package metadata, and the source repository's registered repositories.
