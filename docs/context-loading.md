# Context loading

Tier 0 is the compact entry spine. It identifies the workspace, role, wrapper
version, safety boundary, and one next probe. It does not load all plans,
Product Knowledge, sources, repository instructions, or deep runtime contracts.

Each route has an exact context set and byte ceiling. Conditional evidence is
selected only when its reason exists. A receipt contains references, revisions,
and digests; it is a cache key, never a substitute for primary evidence. On
resume, unchanged references are retained and changed, missing, or newly
required evidence is reloaded.

The deterministic ledger is under `test/context-budget/`. It records selected
paths and bytes for orientation, root/writer/verifier execution, a three-task
resume, and legacy upgrade. No live tokenizer or credential is required for the
filesystem gate.
