# Archived sources

Superseded source material is kept here for provenance, out of the active
`sources/` view. This file marks the directory; it is not a source.

Preserve the original subpath when archiving so provenance stays legible — for
example a retired `system-design/billing/v0.1/` moves to
`.archived/system-design/billing/v0.1/`.

Like everything under `sources/`, this directory is passive: an agent reads an
archived file only when you name it exactly or a plan includes it.
