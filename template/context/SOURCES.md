# Sources

This page explains passive source material: a user-controlled inbox for raw
evidence, briefs, and PRDs. It is not Product Knowledge and is never scanned
wholesale to fill a context gap. An agent reads a source only when the human
names the exact file or a plan explicitly includes it.

A suggested folder layout (raw material, system-design drafts, research,
decisions, data samples, reports, archive) is an ergonomic convention only: the
agent infers no status or authority from folder or file names, and passivity
above still applies.
