# Plans

New plans use `pNNNN-slug/plan.md`, whether linked to an approved intent or
requested directly for a specified outcome. A plan may cover several
repositories and have optional dependencies. Add supporting files inside its
folder only when they help explain the design; link them from the entry's
Details section and assign them in `required_files`. Existing `pNNNN-slug.md`
plans remain readable. Member attribution is `created_by` only. Keep the plan
stable during execution; a separately requested completion adds the result and
`completed_at` to its entry.
Independent review happens only on request. Delivery does not mark a plan done.
