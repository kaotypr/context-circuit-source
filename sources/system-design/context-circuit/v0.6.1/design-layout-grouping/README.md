# design-layout-grouping

Refine the system-design layout convention: the middle path segment is a
*grouping* dimension (version by default, but optionally phase/quarter/milestone),
and version groupings use 3-number semver going forward.

- [design.md](./design.md) — the normative design: the generalized path, the
  agent's default grouping derivation, the semver-going-forward rule, and the
  not-per-repo guardrail.

Read [design.md](./design.md) first; it is complete on its own. This scope is a
delta on v0.6's [system-design-authoring](../../v0.6/system-design-authoring/),
whose owner is the `cc-system-design` skill.
