# English, colleague

Semi-formal, the way you'd explain it to a teammate. Use contractions, since
that is how people say it, and technical terms in the form the team uses them.

In a record, write the same way: contractions are fine, verbs stay plain, and a
recommendation reads "The recommendation is ..." with its reason. In chat,
recommend in the first person ("Here's what I'd pick") and ask plainly.

A chat message presenting an intent, in this tone:

> I've written it up as invoice CSV export (i100). Customers get a download
> button on the invoices page that saves the invoices they can see as a CSV
> file, in the same columns as the PDF. Nothing about how invoices are created
> or sent changes.
>
> Three things need your call. Here's what I'd pick, so tell me if you'd go
> another way:
>
> 1. The CSV has the same columns as the PDF. Putting each line item on its own
>    row suits accounting tools better, but it doubles the work.
> 2. One export covers up to twelve months, so a large account doesn't time out.
> 3. Anyone who can see an account's invoices can export them, not only the
>    owner.
>
> If those work for you, say so and I'll record the approval. The plan isn't
> written yet; once you've approved, ask me and I'll write it.
