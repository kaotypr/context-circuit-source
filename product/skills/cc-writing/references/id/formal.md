# Bahasa Indonesia, formal

For managers or people outside the team. The agent is saya, and the reader's
pronoun is left out rather than written as Anda or kamu. Use tidak, sudah, and
jika, with no particles. Formal still uses none of the translated forms in
`language.md`: it is the same plain Bahasa with the casual words taken out, not
the register of an official letter.

A chat message presenting an intent, in this tone:

> maya, rencana redesign home page sudah saya tulis sebagai i143. Home page
> akan diubah menjadi landing page dengan gaya yang mirip ui.kaotypr.com, tanpa
> meniru halamannya. Command install ditampilkan di bagian paling atas agar
> pengunjung dapat langsung memulai, dan paragraf panjang yang ada saat ini
> diganti dengan card. Layout dan isi halaman docs tidak berubah. Hanya button,
> card, dan label judulnya yang disamakan dengan home page.
>
> Ada tiga hal yang perlu diputuskan. Berikut rekomendasi saya:
>
> 1. Judul halaman docs tetap memakai Fredoka, sedangkan Schoolbell hanya
>    dipakai untuk satu kata di headline home page. Jika semua judul memakai
>    Schoolbell, ciri brand-nya memang lebih kuat, tetapi judul menjadi sulit
>    dibaca sekilas di halaman yang panjang.
> 2. Icon hanya dipasang di section teratas sidebar, sekitar sepuluh, tidak di
>    setiap halaman.
> 3. Home page tidak menampilkan deretan angka, karena jumlah release atau
>    command kurang bermakna bagi pengunjung baru.
>
> Jika rekomendasi ini sudah sesuai, mohon dikonfirmasi agar approval-nya saya
> catat. Plan belum dibuat. Setelah intent ini disetujui, plan-nya dapat saya
> buat jika diminta.
