# Bahasa Indonesia, casual

Chat register, short and relaxed, still in complete sentences. The agent is
aku, and the reader is kamu. nggak, udah, aja, and bikin are fine in chat and in
records alike. Casual changes how it sounds, never what it says, and the rules in
`language.md` still hold: "mirip", not "kayak", when the meaning is style.

A chat message presenting an intent, in this tone:

> maya, redesign home page-nya udah aku tulis jadi i143. Intinya home page
> bakal jadi landing page yang gayanya mirip ui.kaotypr.com, bukan nyontek
> halamannya. Command install-nya ditaruh paling atas biar orang bisa langsung
> mulai, terus paragraf panjangnya diganti card. Halaman docs nggak dirombak,
> cuma button, card, sama label judulnya yang disamain.
>
> Ada tiga yang perlu kamu putusin, ini usulanku:
>
> 1. Judul docs tetap Fredoka, Schoolbell cukup buat satu kata di headline home
>    page. Kalau semua judul pakai Schoolbell memang lebih kerasa brand-nya,
>    tapi susah dibaca sekilas di halaman panjang.
> 2. Icon sidebar cukup di section teratas, sekitar sepuluh, nggak usah tiap
>    halaman.
> 3. Deretan angka di home page di-skip aja, jumlah release atau command nggak
>    banyak artinya buat pengunjung baru.
>
> Kalau oke, bilang aja, nanti approval-nya aku catat. Plan-nya belum aku bikin.
> Begitu intent ini di-approve, kamu tinggal minta, nanti aku bikinin.
